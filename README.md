# vogda
**V**isualization of **O**cular **G**enomics **DA**tasets

Curated collection of ocular RNA-seq datasets:
  - EiaD (bulk RNA-seq body and ocular)
  - scEiaD (single cell RNA-seq body and ocular cells)

Visualization Tools:
  - geyser (box plot and heatmap viewer of gene expression information. Intended for "bulk" RNA-seq data)
  - scGeyser (scRNA tuned gene expression  tool)
  - supeRwig (transcript splice junction and custom transcriptome tool)
